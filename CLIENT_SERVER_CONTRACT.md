# Контракт клиента и сервера — «Аукцион Душ» (Стадия 3)

Документ фиксирует актуальный сетевой протокол третьей стадии (сетевой прототип и логика аукциона) для синхронизации серверной части (Node.js + Colyseus) и графического клиента (Phaser 3 + TypeScript).

## Подключение
- Локальный адрес сервера: `http://localhost:2567` (`ws://localhost:2567`)
- Имя комнаты: `game`
- Вызов подключения: `client.joinOrCreate("game", { name: "Имя игрока" })`
- Лимит комнаты: до 4 игроков (`maxClients = 4`).
- На время начавшегося матча комната блокируется (`this.lock()`), новые подключения отклоняются.

## Состояние игрока (`PlayerState`)
| Поле | Тип | Начальное значение | Назначение |
|---|---|---|---|
| `name` | string | имя из параметров или `Игрок N` | Отображаемое имя |
| `hp` | number | 3 | Текущее здоровье |
| `maxHp` | number | 3 | Максимальное здоровье |
| `souls` | number | 10 | Запас душ (валюта для ставок) |
| `alive` | boolean | `true` | Признак жизни |
| `ready` | boolean | `false` | Готовность в лобби |
| `hasBet` | boolean | `false` | Сделана ли ставка в текущем раунде (сама сумма скрыта) |

## Состояние комнаты (`GameState`)
| Поле | Тип | Значение на Стадии 3 |
|---|---|---|
| `players` | `MapSchema<PlayerState>` | Подключённые игроки (ключ — `sessionId`) |
| `round` | number | Номер текущего раунда (начинается с `1`) |
| `phase` | string | `"waiting"` \| `"item_reveal"` \| `"betting"` \| `"result"` |
| `itemId` | string | ID текущего лота из каталога `items.js` |
| `itemName` | string | Название текущего лота |
| `itemDesc` | string | Описание эффекта лота |
| `auctionWinnerId` | string | `sessionId` победителя последнего аукциона |

## Сетевые сообщения
### Клиент → Сервер
- `ready` — `{ value: boolean }`: переключение готовности в фазе `"waiting"`. Когда готовы все (минимум 2 игрока), матч стартует автоматически.
- `bet` — `{ amount: number }`: отправка скрытой ставки в фазе `"betting"`. Допустимо целое число `0 <= amount <= player.souls` один раз за раунд.

### Сервер → Клиенты
- `event` — `{ text: string }`: строка для журнала событий (всем клиентам).
- `auction_result` — `{ bets: Record<string, number>, winnerId: string, winnerName: string, winnerBet: number }`: раскрытие всех ставок и объявление победителя при переходе в фазу `"result"`.
- `error` — `{ text: string }`: персональное сообщение об ошибке валидации (конкретному клиенту).
