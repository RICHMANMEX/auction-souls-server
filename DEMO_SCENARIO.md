# Стадия 3 — сценарий демонстрации

**Тема стадии:** сетевой прототип и основная игровая логика (скрытый аукцион).

## Что реально реализовано на Стадии 3
- Автоматический старт матча из лобби при готовности всех участников (от 2 до 4 игроков) и блокировка комнаты (`lock()`).
- Цикл раундов с фазами `waiting` → `item_reveal` → `betting` → `result`.
- Каталог лотов (`rooms/items.js`) и показ случайного предмета в начале каждого раунда без повторов подряд.
- Приём скрытых ставок (`bet`) с полной серверной валидацией (проверка фазы, запрет повторной ставки, проверка целого числа от `0` до `souls`).
- Изоляция сумм ставок в приватной коллекции `this.bets` на сервере (в `PlayerState` синхронизируется только флаг `hasBet`).
- Определение победителя аукциона, детерминированное разрешение ничьих со сдвигом приоритета по номеру раунда `(round - 1) % N` и списание душ только у победителя.
- Корректная обработка отключений (`onLeave`) во время торгов без зависания комнаты.
- Автотест `test/test-match.js` на 3 одновременных клиента (**17 проверок, 0 ошибок**).

**Граница стадии (задача Стадии 4):** применение боевых эффектов предметов (урон, лечение, щиты, кража душ), выбор цели (`choose_target`), выбывание при `0 HP` и финал матча (`game_over`).

## Порядок демонстрации (2–3 минуты)
1. **Автотест (главное доказательство работы серверной логики):**
   ```bash
   npm test
   ```
   Показать вывод в консоли: подключение 3 клиентов, отклонение невалидных ставок (`999`, `-1`, `1.5`) и повторной ставки, разрешение ничьей `2:2`, списание душ у победителя и досрочное закрытие торгов при выходе игрока. Итог: `ИТОГ: проверок 17, ошибок 0`.
2. **Живая демонстрация в браузере (2 вкладки):**
   ```bash
   npm start
   ```
   Открыть `http://localhost:2567` в двух вкладках:
   - войти под двумя именами, нажать «Я готов» в обеих вкладках → показать автоматический старт и появление лота раунда;
   - в фазе приёма ставок сделать ставку в первой вкладке → показать, что во второй вкладке статус изменился на «ставка сделана (скрыта)», но сумма не видна;
   - сделать ставку во второй вкладке → показать мгновенное раскрытие ставок, списание душ у победителя и переход ко 2-му раунду.
