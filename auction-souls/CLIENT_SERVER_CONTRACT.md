# Контракт клиента и сервера — «Аукцион Душ» (стадия 2)

Этот документ описывает только то, что реально реализовано в текущем серверном прототипе. Он нужен для подключения клиентской сцены Жени. Ставки, предметы и игровой цикл пока не входят в контракт стадии 2.

## Подключение
- Временная веб-страница: `http://localhost:2567`
- Colyseus client в браузере: `new Client("http://localhost:2567")`
- Явный WebSocket-адрес: `ws://localhost:2567`
- Название комнаты: `game`
- Подключение по имени: `joinOrCreate("game", { name: "Имя игрока" })`
- Максимум игроков: 4.

Важно: `localhost` работает только на том же компьютере, где запущен сервер. Для клиента на другом компьютере потребуется IP компьютера с сервером и настройка доступа по локальной сети.

## Состояние игрока (`PlayerState`)
| Поле | Тип | Начальное значение | Назначение |
|---|---|---|---|
| `name` | string | имя из параметров или `Игрок N` | Отображаемое имя |
| `hp` | number | 3 | Текущее здоровье |
| `maxHp` | number | 3 | Максимальное здоровье |
| `souls` | number | 10 | Игровая валюта |
| `alive` | boolean | `true` | Признак жизни |
| `ready` | boolean | `false` | Готовность в лобби |

Игроки хранятся в `GameState.players` — коллекции `MapSchema`, ключом служит `sessionId`. Текущий игрок: `room.state.players.get(room.sessionId)`.

## Состояние комнаты (`GameState`)
| Поле | Тип | Текущее значение |
|---|---|---|
| `players` | MapSchema<PlayerState> | Все подключённые игроки |
| `round` | number | `1` (зарезервировано на будущее) |
| `phase` | string | `"waiting"` |

На стадии 2 других полей состояния нет. Пока отсутствуют `itemId`, `itemName`, `auctionWinnerId`, `gameWinnerId`, `shields` и `hasBet`.

## Сообщения
### Клиент → сервер
- `ready` с объектом `{ value: boolean }` — устанавливает готовность. Пример: `room.send("ready", { value: true })`.

### Сервер → клиенты
- `event` с объектом `{ text: string }` — событие для журнала.
- Изменения `room.state` синхронизируются Colyseus автоматически.

### Пока НЕ реализовано
Не отправляйте `make_bid` / `bet`, `choose_target` или `restart`: обработчиков для них в текущем `GameRoom` нет. Готовность пока не запускает матч автоматически.

## Минимальный пример подключения
```js
const client = new Client("http://localhost:2567");
const room = await client.joinOrCreate("game", { name: "Женя" });

room.onStateChange((state) => {
  // Обновить кружочки и подписи по актуальным данным state.players.
});
room.onMessage("event", (message) => console.log(message.text));

const me = room.state.players.get(room.sessionId);
room.send("ready", { value: !(me && me.ready) });
```
В клиенте Phaser/PixiJS импорт `Client` зависит от выбранной сборки SDK. Название комнаты, поля состояния и формат сообщения остаются такими же.

## Следующий этап
Перед добавлением ставок команда отдельно согласует название сообщения, формат суммы, проверки, момент раскрытия и ошибки. `make_bid` пока не является реализованным или окончательно утверждённым сообщением.
